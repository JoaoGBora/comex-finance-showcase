# COMEX Finance — Auditoria de Custos de Importação com IA

> 🔒 Código privado (projeto corporativo). Esta página descreve o escopo.

## Problema
Um processo de importação envolve invoice, numerário, impostos, despachante e vários pagamentos. Conferir tudo à mão é demorado, e cobranças indevidas passam despercebidas.

## Solução
Agente de IA que analisa e fecha cada processo de importação:
- Confere **invoice x numerário x pagamentos realizados**
- Verifica se as cobranças do **despachante** estão corretas
- Aponta valores **pagos indevidamente** ou em duplicidade

## Tecnologias
Claude (agentes e skills) · Python · leitura de PDFs e planilhas
